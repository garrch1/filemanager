# File Manager for Android

Простой и удобный файловый менеджер для устройств на базе Android.

## 📱 О проекте

Приложение предназначено для навигации по файловой системе устройства и управления локальными файлами и папками. Проект разработан с использованием современных инструментов Android-разработки и системы сборки Gradle (Kotlin DSL).

## ✨ Основные возможности

Навигация по директориям: просмотр внутреннего хранилища и SD-карты.
Управление файлами: создание, переименование, копирование, перемещение и удаление файлов и папок.
Поиск и фильтрация: быстрый поиск файлов по имени и сортировка по типу, размеру или дате изменения.
Просмотр информации: отображение подробных свойств файлов (размер, путь, дата последнего изменения).
